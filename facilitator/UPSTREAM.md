# Upstream facilitator source

This directory contains an unmodified source snapshot of [Cardano Foundation Cardano x402 facilitator](https://github.com/cardano-foundation/cardano-x402-facilitator) at revision `97add9f`, downloaded on 2 October 2026. This provenance file is the only added file. The upstream Dockerfile builds and runs its native derivation checks on Linux AMD64; the root Compose configuration keeps that platform on Apple Silicon too.

The facilitator targets official `@x402/cardano` and `@x402/core` version 2.26.0. See its original [README](README.md), [API](docs/api.md), and [configuration](docs/configuration.md) for the implementation contract.
